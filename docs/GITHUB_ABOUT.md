Hexive is a distributed Industrial IoT monitoring platform built on a three-tier edge-to-cloud architecture. ESP32 microcontrollers orchestrate a multi-sensor suite — PIR motion, ultrasonic ranging, MQ-series gas analysis, and adaptive noise classification — publishing real-time JSON telemetry via MQTT over Mutual TLS (mTLS) to AWS IoT Core. The Java Spring Boot backend ingests this telemetry through a priority-cascading Decision Engine that classifies environmental conditions (fire hazard, air quality, proximity breach, noise pollution) and persists enriched data via JPA. The system emphasises scalability: stateless REST endpoints enable horizontal backend scaling behind load balancers, while AWS IoT Core natively supports fleet-scale device management. Designed with modularity in mind, Hexive demonstrates Microcontroller Orchestration, cloud-native Distributed Systems patterns, and hardware-software co-design — bridging embedded systems engineering with enterprise application development.
